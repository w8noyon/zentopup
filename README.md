# SM TOPUP

The original single-file HTML app has been separated into a simple project structure:

- `index.html` — page structure and external library imports
- `css/style.css` — the original inline styles
- `js/script.js` — the original inline JavaScript

## Run
Open `index.html` in a modern browser. An internet connection is needed for the external CDN libraries, fonts, and Firebase scripts referenced by the page.

## Note
This is a structural separation of the supplied file; the original app logic and configuration have been preserved as-is.
